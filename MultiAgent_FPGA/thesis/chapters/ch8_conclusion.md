# 第八章 结论

本文围绕"通用多智能体 FPGA 设计全流程自动化框架"这一核心论点，设计并实现了一套面向 DAG 可分解多模块硬件设计的通用自动化框架，并以 AES-128 加密全系统和 LED Chaser 流水灯为验证案例进行了端到端的实验验证。该框架以 OpenHands SDK 为运行底座，以 DeepSeek Chat 双配置策略为 LLM 后端，以 Verilator 仿真器为验证引擎，实现了从规格输入到集成验证通过的全流程自动化。

本文所解决的核心问题是：在硬件设计这一高精度、强约束的领域中，如何设计一套通用的自动化框架来驾驭本质上不可靠的大语言模型，使其成为可信赖的设计自动化组件。框架提出并实现了框架控制架构，将批次推进、验证判定、修复决策等控制逻辑全部内化到状态机和数据契约中，LLM 只负责执行被明确分配的局部任务。框架的三个核心创新点——基于状态机的多智能体协作架构、四层分级验证体系与检查点协议、以及六层约束驾驭引擎——的详细设计与验证已在第三章 §3.6 中进行了总结。

实验结果表明，本文提出的框架在 AES-128 案例上实现了全流程无人工干预的端到端执行，全部 4 个模块均在首次生成后直接通过验证，3 个集成回归测试全部通过；LED Chaser 案例通过 YAML 蓝图驱动机制在不修改任何框架代码的前提下完成了全流程执行，验证了框架的跨设计通用性；通过 Vivado 自动化脚本实现了从 AI 生成代码到 FPGA 比特流的完整闭环，两个设计均成功生成比特流文件。

当前 RTL 综合与布局布线阶段尚未深度集成到验证框架中，Vivado 脚本作为独立工具运行，致使框架无法自动解读综合报告以指导 RTL 修改，也不具备根据资源利用率报告进行自动优化的能力；为此，设计将引入 Agent 自主学习机制，基于修复历史在每次成功修复后自动触发技能更新流程，形成动态增长的领域知识库以逐步提升首次通过率，同时将 Vivado 脚本升级为框架的正式 L3 验证层，通过设计 Vivado 适配器将综合与实现封装为 MCP 工具调用，最终实现从 L0 到 L3 再到集成阶段的完整验证闭环。
